# nftechie/homebrew-tap

Homebrew casks for [Snapcap](https://github.com/nftechie/snapcap), the free, open-source Loom alternative for Mac.

```sh
brew install --cask nftechie/tap/snapcap
```

Update with `brew upgrade --cask snapcap`, uninstall with `brew uninstall --cask snapcap` (add `--zap` to also remove preferences; your recordings are never touched).

Casks here are generated by the Snapcap release workflow from [`packaging/homebrew/snapcap.rb`](https://github.com/nftechie/snapcap/blob/main/packaging/homebrew/snapcap.rb). Please open issues and pull requests in the [main repository](https://github.com/nftechie/snapcap).
